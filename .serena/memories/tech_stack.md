# Tech Stack

- TypeScript, React 19, Next.js 16.
- Visual engines: Three.js, React Three Fiber, Drei, and Phaser.
- npm with committed `package-lock.json`; Node version must be pinned by the repository.
- Vitest for unit/component tests; Playwright for browser, visual, responsive, accessibility, and network-isolation coverage.
- ESLint and `tsc --noEmit` are required static gates.
